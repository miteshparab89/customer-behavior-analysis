# 📊 Customer Behavior Analysis Dashboard

## 📌 Overview

This project analyzes customer behavior data to uncover patterns and insights that can support better business decisions.
It combines **Excel, Python, and Power BI** to perform an end-to-end data analysis workflow—from data cleaning to interactive dashboard creation.

---

## 🎯 Objectives

* Clean and preprocess raw customer data
* Perform exploratory data analysis (EDA)
* Identify customer trends and patterns
* Build an interactive dashboard
* Present insights in a simple and clear way

---

## 🛠️ Tools & Technologies

* **Excel** – Initial data handling
* **Python (Pandas, Matplotlib, Seaborn)** – Data cleaning & analysis
* **Power BI** – Dashboard and visualization

## 🔍 Workflow

### 1. Data Cleaning

* Removed missing and inconsistent values
* Standardized column formats
* Prepared dataset for analysis

### 2. Exploratory Data Analysis (EDA)

* Used `df.info()` to understand data structure
* Used `df.describe()` for statistical summary
* Checked for missing values
* Analyzed distributions and relationships

### 3. Data Visualization

* Created bar charts and distribution plots
* Identified patterns in customer behavior

### 4. Dashboard (Power BI)

* Built an interactive dashboard
* Added filters (slicers)
* Highlighted key insights
* Focused on clean and simple design
